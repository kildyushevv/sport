# Sport — приложение для тренировок на SwiftUI

Чёрный фон, лаймовый акцент (`#C6FF00`), крупная типографика и спортивные фотографии.
Все экраны заполнены демонстрационными данными. iOS 17+, без сторонних зависимостей.

## Экраны

| Вкладка | Что внутри |
|---|---|
| **План** | Переключатель «Зал / Дома». Зал: полоса недели, прогресс недели, карточка дня, тренировка по подходам с отдыхом. Дома: 6 интервальных программ без инвентаря (см. ниже) |
| **Каталог** | 47 упражнений, поиск, фильтр по группе мышц и «Без инвентаря», детальный экран с техникой и советами, добавление в план |
| **Таймер** | Интервалы (Табата, 40/20, EMOM, свои значения), таймер отдыха, секундомер с кругами, вибро-отклик |
| **История** | Сводка за месяц, тренировки по месяцам, детали каждой тренировки с подходами |
| **Прогресс** | Недельный объём, вес тела, расчётный 1ПМ (Swift Charts), личные рекорды, серия недель |

Демо-история (≈26 недель) генерируется детерминированно относительно текущей даты, поэтому графики выглядят одинаково при каждом запуске, а «сегодня» всегда актуально.

## Домашние тренировки

На вкладке **План** переключатель **Дома** открывает круговые интервальные программы только со своим весом, с упором на похудение:

| Программа | Формат | Уровень |
|---|---|---|
| Сжигатель жира | 40 с работа / 20 с отдых, 3 раунда, 8 упражнений | Средний |
| Старт с нуля | 30/30 с, без прыжков | Новичок |
| Табата-экспресс | 20/10 с, 4 раунда, около 9 минут | Средний |
| Без прыжков | 40/20 с, тихо, для квартиры | Новичок |
| Пресс и кор | 40/15 с | Средний |
| Всё тело | 45/15 с, 3 раунда, 8 упражнений | Продвинутый |

Тренировка идёт на таймере: 10 секунд на подготовку, затем чередуются работа и отдых, на экране видны текущее упражнение, подсказка по технике и «Дальше: …». Завершённая тренировка сохраняется в историю с меткой «Дома». Значения ккал — **ориентировочная оценка** по времени и интенсивности программы, а не измерение.

## Анимации техники

**GIF из датасета.** Для 16 из 23 упражнений без инвентаря показывается GIF из
[hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)
(анатомическая модель, светлая карточка, подпись «© Gym visual — https://gymvisual.com/»).
Это медиа Gym visual: MIT-лицензия датасета на него не распространяется, **для публикации
приложения нужна лицензия у Gym visual** — подробности в `THIRD_PARTY_NOTICES.md`.
GIF лежат в `Sport/Resources/ExerciseGIFs/`, список — в `Sport/Data/ExerciseGifs.swift`.
Скорость GIF задаётся константой `ExerciseGifView.gifPlaybackSpeed` (сейчас 1,4; больше — быстрее).
Обновить или поменять соответствия: правьте `MAPPING` в `tools/import_gifs.py` и запустите
`python3 tools/import_gifs.py /путь/к/exercises-dataset`.

Для остальных 7 упражнений (шаги в стороны, приседания, выпады назад, планка, суперман,
отжимания «горкой», кошка-корова) точных аналогов в датасете нет, и для них показывается
нарисованная анимация, описанная ниже. Она же служит запасной, если GIF не найден.

**Нарисованные анимации.**

У каждого из 23 упражнений без инвентаря есть и нарисованная анимация «как выполнять»: схематичная фигура, нарисованная кодом (`Canvas` + `TimelineView`), с подписью текущей фазы движения («Опускаемся», «Выжимаем вверх»). Анимация показывается в карточке упражнения («Каталог») и во время домашней тренировки; пауза тренировки останавливает и анимацию. При включённой настройке «Уменьшить движение» вместо плавной анимации показываются ключевые позы по очереди.

Общая скорость воспроизведения задаётся константой `ExerciseAnimationView.playbackSpeed` (сейчас 0,65; меньше — медленнее).

Фигура строится по углам суставов (прямая кинематика), поэтому длины конечностей не меняются, а стопы и ладони не скользят по полу.

Как править позы:

1. Откройте `tools/anim_defs.py` и поправьте углы нужного упражнения (описание углов — в `tools/anim_core.py`).
2. Посмотрите результат: `python3 tools/make_animations.py --preview out.png <id упражнения>` (нужен Pillow).
3. Перегенерируйте данные: `python3 tools/make_animations.py` — файл `Sport/Data/ExerciseAnimations.swift` создаётся автоматически, вручную его не редактируйте. Скрипт завершится с ошибкой, если у какого-то упражнения без инвентаря нет анимации.

Геометрия в Python (`tools/anim_core.py`) и в Swift (`Sport/Models/Motion.swift`) зеркальна; тест `testGeometryMatchesPythonReference` сверяет их на эталонных значениях.

## Тесты

```sh
xcodegen generate
xcodebuild test -scheme Sport -destination 'platform=iOS Simulator,name=iPhone 15'
```

Тесты (`SportTests/`) проверяют сборку интервалов, учёт выполненных интервалов, целостность демо-данных (уникальные id, домашние программы используют только упражнения без инвентаря) и анимации (есть у каждого домашнего упражнения, фигура не уходит за пол и границы, Swift-геометрия совпадает с Python).

## Сборка

Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```sh
brew install xcodegen
xcodegen generate
open Sport.xcodeproj
```

Выберите схему `Sport`, симулятор iPhone с iOS 17+ и запустите. Перед выпуском замените
`PRODUCT_BUNDLE_IDENTIFIER` (`com.example.sport`) в `project.yml` и укажите свою команду подписи.

## Фотографии

Все адреса снимков находятся в одном файле — `Sport/Data/PhotoCatalog.swift` (прямые ссылки на Unsplash).

- Идентификаторы снимков **не проверялись на доступность** — код писался в среде без доступа к сети.
  Если какая-то ссылка не открывается, `RemotePhoto` показывает тёмную градиентную заглушку, так что экран не ломается.
- Чтобы заменить фото, поправьте идентификатор в `PhotoCatalog.ids` или подставьте любой другой URL.
- Для работы без сети добавьте изображения в `Assets.xcassets` и замените `RemotePhoto(url:)` на `Image("имя")`.
- Проверьте лицензию на изображения, прежде чем публиковать приложение.

## Структура

```
Sport/
  App/         точка входа, TabView
  Theme/       цвета, шрифты, кнопки, форматирование (русская локаль)
  Models/      модели данных
  Data/        демо-данные и каталог фотографий
  Store/       AppStore (@Observable) и Analytics (чистые функции для графиков)
  Components/  RemotePhoto, PhotoCard, чипы, плитки, вибро-отклик
  Features/    Plan, Catalog, Timer, History, Progress
SportTests/    unit-тесты таймера, демо-данных и анимаций
tools/         генератор нарисованных анимаций и импорт GIF (Python)
```

## Ограничения

- Данные хранятся только в памяти: завершённые тренировки пропадают после перезапуска.
  Следующий шаг — сохранение через SwiftData или JSON.
- Таймер считает время по метке окончания, но уведомление при сворачивании приложения не отправляет.
- Код и тесты писались без Xcode и не запускались, поэтому при первой сборке возможны мелкие замечания компилятора.
